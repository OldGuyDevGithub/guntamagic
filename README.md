<p><span style="font-size:22px;"><strong>Guntamagic Custom Component for Home Assistant</strong></span></p>
<img src="https://github.com/OldGuyDevGithub/guntamagic/blob/main/custom_components/guntamagic/logo.png" alt="kessel" />

<p>A custom Home Assistant integration that connects to your Guntamatic heating system via the Modbus/WEB interface and exposes sensors and controls directly in Home Assistant.</p>

<p>For the integration to work you need the Modbus key for your Guntamatic device, available at <a target="_blank" rel="noopener noreferrer" href="https://www.guntamatic.com/">https://www.guntamatic.com/</a></p>

<h2>Supported Devices</h2>
<ul>
  <li>Guntamatic BMK</li>
  <li>Guntamatic BMK Hybrid</li>
  <li>Guntamatic BMK Vario (Wood/Pellets)</li>
  <li>Guntamatic Biostar</li>
  <li>Guntamatic Powerchip</li>
</ul>

<h2>Features</h2>
<ul>
  <li><strong>Sensors</strong> — boiler temperature, buffer temperatures, heating circuits, hot water, CO₂, power, operating hours, fuel counter and many more</li>
  <li><strong>Controller Program select</strong> — set the boiler program (Off / Normal / Hot Water / Heating / Setback, and Manual for supported devices) directly from Home Assistant</li>
  <li><strong>Heating Circuit Program select</strong> — set the program for each of up to 9 heating circuits (HK 0–8) individually</li>
  <li><strong>Multi-language</strong> — full translations in German, English, French and Italian</li>
</ul>

<h2>Installation</h2>
<p>Install via <a href="https://hacs.xyz/" target="_blank">HACS</a> by adding this repository as a custom repository, or copy the <code>custom_components/guntamagic</code> folder into your Home Assistant <code>config/custom_components</code> directory.</p>
